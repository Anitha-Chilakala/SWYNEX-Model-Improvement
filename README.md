# SWYNEX Model Improvement

## Project Overview

This project focuses on improving and validating a Random Forest machine learning model using the Titanic dataset for SWYNEX Internship Task 3.

## Tasks Performed

- Prepared the Titanic dataset
- Trained a baseline Random Forest model
- Applied hyperparameter tuning using GridSearchCV
- Used 5-fold cross-validation
- Evaluated the tuned model using multiple metrics
- Compared baseline and improved model performance
- Created a model comparison graph

## Dataset

Titanic dataset with `Survived` as the target variable.

## Model Used

- Random Forest Classifier
- Hyperparameter-tuned Random Forest Classifier

## Tools Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

## Conclusion

The baseline and tuned Random Forest models were compared using multiple evaluation metrics. The findings are based on the actual evaluation results.
